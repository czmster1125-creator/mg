# TIDEBLOOM · 潮汐小岛

基于《海岛钓鱼大亨 · 正式开发 PRD V1.0》的可玩 3D 浏览器 Demo。欧美休闲海岛美术方向，青绿海水、奶油色建筑和珊瑚色 UI。手机竖屏触控布局；电脑端也使用居中的 9:16 画框。

## 开始试玩

需要 **Node.js 24**（使用内置 SQLite）和支持 WebGL 的现代浏览器。

```bash
cd /workspace/mg
npm ci
npm run dev
```

开发服务器默认端口 **5173**，监听 `0.0.0.0`。本机浏览器打开该端口即可。`PORT=其他端口 npm run dev` 可改端口。

正式构建与启动：

```bash
npm run build
npm start
```

服务器须保持运行，不能直接双击 `index.html`。当前云环境已经安装依赖并启动预览服务。运行环境快照不保留进程，新任务需要重新启动。

## 玩法（0.16）

新手核心航程缩为六步，随行／喂养改为鱼缸内的可选配置，旧进度一次性迁移且总补给规模保留。新增每周海洋观察册、可解锁鱼缸主题、三种可建设养护的实际鱼缸栖地，以及经营／冒险随行预设。六岛设施改用六种不同模型，后期 NPC 收益按已开放海域成长；出海中点击任务或手帐会在本次结算后打开。规则与模拟边界见 [0.16 观察与养成](docs/RESEARCH_V016.md)。

新增每周主题航海五阶段、六岛建设设施与特殊出海、本轮目标／收获手帐、同一 NPC 的三段冒险线索、重复鱼获的体重纪录／默契、海岛与小艇外观、每周海岛灯会，以及两位真实好友共建灯塔。自动钓鱼可按本轮目标停止；事件和好鱼挑战完成后才收尾。入口沿用任务、海岛、装备和钓鱼按钮旁的本轮手帐，没有新增主 Tab。规则、资源预算与边界见 [0.15 核心循环](docs/CORE_LOOP_V015.md)。

每日订单改为资源栏下方的任务卡，直接展示具体目标、进度和奖励，有可领奖订单时优先展示。旁边的“任务”整合主线章节、新手航程和每周委托。设置仅保留声音、账号与好友、安装和帮助；装备／钓鱼偏好、航线／故事／防守／布置分别放回钓鱼和海岛。随行配置与提示集中在鱼缸，不再占据三页的全局任务栏。入口与设计说明见 [0.14 任务与入口](docs/NAVIGATION_V014.md)。

圆形主按钮改为钓竿图标，剩余钓鱼次数移到按钮正上方；短按钓一次，长按 0.6 秒开启自动钓鱼，松手后持续，再点同一按钮停止。取消独立 AUTO 按钮，自动状态以绿色按钮和环形动画提示。交互及截图见 [0.13 钓鱼按钮](docs/FISHING_CONTROLS_V013.md)。

本版调整为 **潮汐钓竿、贝光鱼钩、航海罗盘** 三件十级装备，提供真实概率和奖励对照；旧装备投入自动迁移补偿。船长每 100 经验升级，可查看称号节点、经验来源和升级补给。首次偷袭空容器报错已修复，攻击／偷袭改为全屏交互登岛，四位 NPC 分别保存金库、护盾与损伤。规则见 [0.12 装备与成长](docs/EQUIPMENT_CAPTAIN_V012.md)，未完成的长线部分见 [核心循环复查](docs/CORE_LOOP_REVIEW_V012.md)。

底部为 **海岛、钓鱼、鱼缸**。海岛内直接点击潮汐小屋、码头小铺、匠人小屋和伙伴小屋四栋生产建筑，扩张解锁更多设施。抛竿可获得鱼、NPC 攻击、独立偷袭、宝藏探索、护盾或补给；首次鱼获永久成为鱼宠。鱼缸内喂养、设置随行并领取收藏奖励，宠物分别辅助经营、攻击、探索与偷袭。

轻触钓鱼按钮自动找点并出海；点击鱼群直接滑行开钓，长按开启的自动钓鱼遇到事件会暂停。好鱼自动触发收线挑战，支持开关和保底收获，挑战不另扣鱼饵。三页重排、操作与保底规则见 [0.11 出海与布局](docs/FOCUS_SPIN_V011.md)，按钮交互以 0.13 说明为准。

## 存档与实现边界

数据库位于 `.data/tidebloom.sqlite`，`DATA_DIR` 可以覆盖。HTTP-only Cookie 是当前浏览器的角色凭据，清除 Cookie 会创建新角色；数据库与 Cookie 同时保留时重启服务可继续游戏。绑定账号后可在连接同一服务器的其他浏览器恢复。密码与恢复密钥用于登录／找回，部署时请备份数据库。

这是用于评审玩法和美术方向的 **Web Demo**，不是 PRD 全部 P0 的上线交付：尚未适配微信小游戏运行时，没有运营埋点后台、广告/支付、活动或船队远征；鱼宠养成与收藏奖励已实现基础版本。六个地区共享相邻地块逻辑，但地块投影、港口结构和自然景观已区分；地区数据独立，切换后旧地标进度保留；各地标采用参数化模型生成 0–5 级外观，等级变化会增加主体、楼层或设施；并非手工制作的 50 套独立美术资源。历史基地居民与小狗模型为场景装饰；可培养的宠物为鱼缸鱼类。

手动挑战回传输入时序，由服务端回放验证后发奖；这可阻止直接伪造成功，但不能视为商业化反作弊审计。速钓随机性与所有经济变更在服务端执行。当前进程内串行事务可防重复操作，不能视为已完成多节点生产架构、安全审计或真实移动设备性能验收。断线重试会复用请求编号；若连续断线，刷新从数据库恢复，尚无离线请求队列。

## 验证

```bash
npm test          # 140 项规则、模型、账号、航海、协作与观察养成测试
npm run test:e2e  # Chromium 端到端测试，需要本机 Chromium
npm run build
npm run test:pwa  # 生产包安装资源缓存、断网与联网恢复
```

浏览器测试默认使用 `/usr/bin/chromium`，其他路径可设置 `CHROMIUM_PATH`。测试创建独立 Cookie 角色；测试数据留在本地数据库，不影响试玩角色。Playwright 的软件 WebGL 渲染用于自动化验证，不代表手机 GPU 性能结果。

## 工程结构

- `src/scene.js` / `src/motion.js`：竖屏钓场、驾船运动与钓鱼动画
- `src/island-scene.js`：海岛与基地场景、居民、建筑点选与收益气泡
- `src/town-models.js` / `src/town.css`：分阶段建筑模型与场景交互排版
- `src/fish-preview.js`：3D 鱼获展示与资源释放
- `src/main.js` / `src/style.css` / `src/portrait.css`：UI、交互与竖屏排版
- `shared/fishing.js` / `shared/objectives.js`：搏鱼时间步规则、成长目标选择
- `server/config.js`：鱼池、价格、等级、委托和建造配置
- `server/engine.js`：经济规则、服务端时间结算和状态变更
- `server/index.js`：HTTP、Vite 和 SQLite 事务服务
- `docs/screenshots/`：实际浏览器截图
- `docs/THIRD_PARTY.md`：开源来源与素材说明

开发使用现有 `/workspace/mg` checkout；云任务本身隔离，不需要额外创建 Git worktree。源码仓库：https://github.com/czmster1125-creator/mg 。此项目尚未公开部署。
