# TIDEBLOOM · 潮汐小岛

基于《海岛钓鱼大亨 · 正式开发 PRD V1.0》的可玩 3D 浏览器 Demo。欧美休闲海岛美术方向，青绿海水、奶油色建筑和珊瑚色 UI。手机竖屏触控布局；电脑端也使用居中的 9:16 画框。

## 开始试玩

需要 **Node.js 24**（使用内置 SQLite）和支持 WebGL 的现代浏览器。

```bash
cd /workspace/mg
npm ci
npm run dev
```

开发服务器默认端口 **5173**，监听 `0.0.0.0`。本机浏览器打开该端口即可。`PORT=其他端口 npm run dev` 可改端口。

正式构建与启动：

```bash
npm run build
npm start
```

服务器须保持运行，不能直接双击 `index.html`。当前云环境已经安装依赖并启动开发服务。运行环境快照不保留进程，新任务需要重新启动。

## 玩法

1. 点击水面圆环选择鱼群，小艇转向并驶近；点击或拖动空白水面可以驾船。移动不消耗鱼饵，抛竿前会自动靠近当前鱼群。
2. 点击「抛竿钓鱼」，到达钓点后约 2.7 秒显示鱼获，包含抛竿、等待、鱼跃入舱动画。倍率 ×1/×2/×5 对应独立鱼获与鱼饵消耗。
3. 打开「鱼舱」出售鱼获换金币。珍稀鱼自动锁定，可以手动解锁；出售保留图鉴记录。
4. 进入「我的海岛」，点击空地的 `+`、建筑本体或名称标签来建设；底部按钮优先选择尚未建造的地块。每 5 建设点自动获奖，25 点解锁第二片永久区域。
5. 「基地」进入 3D 小镇，点建筑升级，点收益气泡或底部按钮领取全部已积累收益；「装备」强化三种装备；点击海域名称解锁珊瑚海岸。
6. 「手动挑战」按住蓄力、松开抛竿，出现咬钩提示时提竿。交替按住与松开收线，使张力不长时间进入红区。成功获得稀有鱼。

初始资源：350 金币、40 鱼饵、8 零件；基地含一次性欢迎补给。未开放广告或付费。音效可在右上角关闭。空格可抛竿，Esc 关闭面板。

详情见 [建设与基地说明](docs/TOWN_UPDATE.md)。截图位于 `docs/screenshots/town/`。升级价格、产出与原有存档格式保持兼容；已有建筑直接显示对应等级。

## 已实现

- 实时 Three.js 3D 场景、动画海水、渔船移动、水花、海鸟、建筑升级外观、两种海域装饰。
- 服务器决定鱼获、价格与资源变化；12 格鱼舱、独立鱼 ID、批量出售、锁鱼、12 鱼种图鉴。

- 桌面和手机自适应界面、可关闭音效、键盘焦点与对话框焦点约束。

## 存档与实现边界

数据库位于 `.data/tidebloom.sqlite`，`DATA_DIR` 可以覆盖。HTTP-only Cookie 是当前浏览器的角色凭据，清除 Cookie 会创建新角色；数据库与 Cookie 同时保留时重启服务可继续游戏。没有账号登录或跨设备同步，部署时请备份数据库。

这是用于评审玩法和美术方向的 **Web Demo**，不是 PRD 全部 P0 的上线交付：尚未适配微信小游戏运行时，没有运营埋点后台、广告/支付、活动、船队远征或宠物养成。图鉴章节奖励暂未实现。两个地区复用同一 3D 岛屿布局，地区数据独立，切换后旧地标进度保留；各地标采用参数化模型生成 0–5 级外观，等级变化会增加主体、楼层或设施；并非手工制作的 50 套独立美术资源。基地居民与小狗是场景动画，尚未接入居民任务或宠物养成。

手动挑战校验会话、耗时和一次性结算，但客户端报告操作结果；没有正式反作弊/行为回放验证。速钓随机性与所有经济变更在服务端执行。当前进程内串行事务可防重复操作，不能视为已完成多节点生产架构、安全审计或真实移动设备性能验收。断线重试会复用请求编号；若连续断线，刷新从数据库恢复，尚无离线请求队列。

## 验证

```bash
npm test          # 17 项经济/状态机 + 4 项运动 + 4 项建筑模型测试
npm run test:e2e  # Chromium 端到端测试，需要本机 Chromium
npm run build
```

浏览器测试默认使用 `/usr/bin/chromium`，其他路径可设置 `CHROMIUM_PATH`。测试创建独立 Cookie 角色；测试数据留在本地数据库，不影响试玩角色。Playwright 的软件 WebGL 渲染用于自动化验证，不代表手机 GPU 性能结果。

## 工程结构

- `src/scene.js` / `src/motion.js`：竖屏钓场、驾船运动与钓鱼动画
- `src/island-scene.js`：海岛与基地场景、居民、建筑点选与收益气泡
- `src/town-models.js` / `src/town.css`：分阶段建筑模型与场景交互排版
- `src/fish-preview.js`：3D 鱼获展示与资源释放
- `src/main.js` / `src/style.css` / `src/portrait.css`：UI、交互与竖屏排版
- `server/config.js`：鱼池、价格、等级、委托和建造配置
- `server/engine.js`：经济规则、服务端时间结算和状态变更
- `server/index.js`：HTTP、Vite 和 SQLite 事务服务
- `docs/screenshots/`：实际浏览器截图
- `docs/THIRD_PARTY.md`：开源来源与素材说明

开发使用现有 `/workspace/mg` checkout；云任务本身隔离，不需要额外创建 Git worktree。源码仓库：https://github.com/czmster1125-creator/mg 。此项目尚未公开部署。
