# 0.11 三页布局与自动出海

海岛、钓鱼、鱼缸各保留一个视觉重点，原有四栋建筑、统一海岛物资和潮汐寻珠继续保留。

## 界面层级

- 海岛：上方为岛名与故事入口，中间为 3D 建筑与扩张格，底部只保留下一阶段目标、扩张主按钮、领取产出和护盾。六岛切换进入岛名后的航线图；战报、地标、订单等次要内容收进右上角手记。
- 钓鱼：场景中保留鱼群圆环，底部用圆形立体 SPIN 按钮突出出海动作，倍率与 AUTO 分列两侧。取消重复叠加的钓点提示和独立手动挑战主入口。
- 鱼缸：先展示伙伴水族箱，再展示三个实际随行位置（未开放位置有锁）、下一档收藏奖励，最后是伙伴卡片。加成明细和全部收藏奖励通过“查看加成”进入；支持全部／已发现筛选。

头像仍进入账号与好友。顶部礼物进入订单，手记设置包含故事、航线、周委托、防守、偷袭教学、装备、海域、地标、音效、帮助与可选收线练习。独立练习保留旧规则，不是普通鱼的必要步骤。

## SPIN、点鱼群和 AUTO

1. 点击 SPIN：自动选择钓点，船滑行到鱼群旁，再请求一次抛竿，不需要再次确认。开启好鱼挑战时优先珊瑚秘境的稀有权重，关闭时优先大鱼点的体型收益；这不是宣称存在动态刷新却未实现的钓点评级系统。
2. 手动拖动水面免费驾驶。点击鱼群圆环则直接驶向它并开始一次钓鱼，不再要求额外点 SPIN。航行时可快速改选另一鱼群，只对最终发出的这一次钓鱼请求扣饵。
3. AUTO 连续进行找点、抛竿和普通鱼结算，普通鱼用简短收获提示，不反复弹阻断式奖励面板。每次请求仍由服务端结算，倍率 ×1 / ×2 / ×5 对应鱼饵消耗。
4. 遇到攻击、偷袭、寻珠、奇遇等事件或好鱼挑战时暂停 AUTO。关闭事件面板不会自动重启连续出海。
5. 再点 AUTO 可停止后续循环；切换页面、打开功能面板、进入后台、断网或鱼饵不足也会停止。离开时尚在找点的航行可取消，不发出钓鱼请求，不扣次数。已发出的请求仍按服务端真实结果结算。

连续状态只保存在当前页面，不跨刷新或后台自动续跑。未完成的海上事件依然按原有存档机制保存。

## 好鱼挑战与保底

默认打开“好鱼上钩时挑战”，可在右上角手记关闭，偏好保存在当前设备。普通／优秀鱼直接收获；正常抛竿抽中稀有／史诗鱼时自动弹出收线挑战，毋须主动挑选手动模式。

服务端先锁定本次抛竿的物种、体重、售价与整批鱼获，进入挑战不重新随机，也不额外消耗鱼饵。倍率抛竿中只要出现一条好鱼，整批暂存为一场挑战；通过后一次结算整批，避免把一竿拆成多次收费。

- 成功：按原有输入回放规则验证提竿与张力操作，收获原鱼，额外获得本批鱼获金币的 20%。
- 保底：可随时选择保底收获；失败、退出、刷新或服务端超时也以基础价值收获原鱼，不损失已遇到的好鱼，不退回或重复扣除原抛竿鱼饵。
- 关闭挑战开关：后续好鱼和普通鱼一样自动收获，不领取挑战成功额外奖励。
- 进行中的挑战阻止再次抛竿、更换海域与养成操作；挑战编号、启动状态、次数、时间与成功回放均由服务端验证，不允许重置计时或重复发奖。

离线超过 60 秒的稀有鱼挑战在下一次服务端结算时自动按基础价值收获；该超时机制与不返还鱼饵的旧收线练习分开处理。捕鱼、图鉴、鱼宠、引导、订单与周委托的计数在实际收获时统一推进一次。

## 验证

`npm test` 包括 96 项规则、模型和账号测试，新增六项检查普通鱼直接收获、挑战开关、整批暂存、一次扣饵、防重抽与计时重置、刷新保底、输入回放成功奖励、失败／取消／超时的原鱼结算、非法编号和设置拒绝。

`node scripts/capture-v11.mjs` 使用隔离生产服务器、展示存档及真实请求，验证三页布局、360×640 圆形按钮、鱼群点击直接钓鱼、SPIN 寻找稀有点、好鱼自动挑战、保底收获、离开找点阶段不扣饵、AUTO 连续发起下一竿、事件暂停和进入后台停止。六张截图在 `docs/screenshots/focus-v11/`，固定鱼种保底和成熟建筑只是检查夹具，不代表真实玩家进度。

浏览器回归仍覆盖完整新手流程、捕鱼与收线、建造和修复、贝壳匹配及刷新、订单、航线、账号、好友、离线互访和复仇。使用 Chromium 软件 WebGL，不能替代实体手机性能验收。AUTO 和保底提高便利性；真实长期经济平衡仍需玩家数据。本轮没有发布云环境。
