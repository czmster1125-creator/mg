# 0.13 钓鱼按钮

主按钮使用钓竿图标和“钓鱼”文字，保留圆形外观。原右上角的鱼饵余额移到按钮正上方，显示“剩余 N 次”；按钮内显示每竿消耗，左侧保留 ×1／×2／×5 倍率。次数来自同一份服务端鱼饵余额，奖励仍可超过自然恢复上限 50 次，没有新增资源或改变扣除规则。

- 短按：自动寻找钓点，滑行后钓一次。点鱼群仍可直接前往并开钓。
- 长按 600 毫秒：环形进度完成后开启自动钓鱼，按钮变绿并显示“自动中”。松手继续，不额外触发一次短按。
- 自动时再次点击或长按同一按钮：停止后续自动钓鱼。尚在滑行时取消本竿，不扣次数；已发送的捕鱼请求完成本次结算，不撤销已消耗的次数。
- 遇到攻击、偷袭、寻宝或好鱼挑战时暂停；切页、进入后台、断线或次数不足也停止，返回后由玩家主动开启。

移除独立 AUTO 按钮。手势移动超过 14 像素、触摸被系统取消或窗口失焦会取消未完成的长按；右键／触摸菜单被抑制。按钮聚焦时 Space／Enter 同样支持短按和长按，自动时 Escape 停止。无障碍标签会提示当前操作，减少动态效果设置下关闭循环动画。

浏览器专项覆盖按钮与计数位置、一次短按单次请求、触屏长按松手、航行中停止不扣次数、连续自动后停止、拖动与触摸取消、键盘、事件暂停。检查 360×640、390×844、480×857 三种竖屏布局；使用 Chromium 触屏模拟和软件 WebGL，不代表真实手机性能验收。
