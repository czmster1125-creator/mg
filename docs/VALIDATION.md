# Demo 验证记录

验证环境：Node.js 24.22.1；Chromium；1440×1000 桌面与 390×844 竖屏视口。使用 Playwright 的软件 WebGL 渲染，未进行实体手机或微信运行时测试。

- `npm ci --ignore-scripts`：成功从锁文件重建依赖。
- `npm run build`：通过，生成生产静态资源。
- `npm test`：17 项通过、0 失败、0 跳过。
- `npm run test:e2e`：5 项通过、0 失败、0 跳过。
- 生产模式额外检查：HTML 与 JS 资源可访问、API 生成鱼获、关闭并重新启动服务器后使用同一 Cookie 恢复 SQLite 存档，均通过。

## 浏览器验证的真实流程

1. 抛竿 → 奖励 → 鱼舱 → 解锁（若需要）→ 出售 → 地标建造 → 基地领取 → 刷新恢复 → 图鉴保留。
2. 390px 手机视口无横向溢出，切换钓点、×2 独立鱼获与实际鱼饵扣除。
3. 同一 requestId 重试返回相同结果；非法跨区域建造不修改钱包或地标。
4. 手动蓄力、等待上钩、窗口提竿、交替收线/放松，成功入舱一条锁定稀有鱼，只扣一份鱼饵。
5. 鱼舱满仓时引导出售且不扣饵，装备升级、Esc 关闭面板。

测试中修正了奖励渲染引用被临时替换的按钮元素、钓点按下时 CSS transform 导致命中区位移、低帧率收线计时偏慢三个问题。最终结果为上述全部通过。
