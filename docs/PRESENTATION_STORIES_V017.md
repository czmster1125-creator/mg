# 0.17 钓鱼演出与海上故事

本轮按“钓鱼与事件表现 → 事件分支与主题内容”完成，继续使用海岛、钓鱼、鱼缸三个主页面。核心经济、装备、鱼宠与真实互访沿用原存档；没有发布线上环境。

## 钓鱼的动作衔接

普通钓鱼现在分为抛竿、浮漂等待、真实结果返回后的咬钩、收线和鱼跃入船。请求仍在等待时只播放浮漂与水面，不提前播放咬钩或满进度；服务端失败时停止演出并显示错误，不在客户端制造鱼获。

鱼竿使用预建弯曲形态随张力平滑变化，船长随提竿后仰，收线时浮漂靠近小艇，镜头轻轻推进。出水鱼使用实际鱼种的模型，包括长鱼、鳐、海马等不同体形；替换前释放旧模型。水花、波纹继续使用固定对象池，不按帧创建新的几何体。

好鱼在真实咬钩时交接到手动挑战，不先播放一次已收获的普通收线；挑战仍使用原来的服务端时序校验与保底。

声音区分抛竿、落水、咬钩、收线、破盾、命中、普通收获和新发现；沿用声音开关。浏览器的自动播放限制仍生效。减少动态效果偏好会缩短普通演出、减小跃起幅度并停止镜头推进，不影响真实结算与挑战的输入校验。

六个海域分别采用海湾、港雾、珊瑚、暖流、冰海和星海水色，并增加对应岸边浮灯、珊瑚、黑岩、浮冰或遗迹构件。它们共享可操作水道和钓点布局，是现有场景的主题扩展，不声称已经制作六套全新独立地图。

攻击中镜头向当前目标靠近，护盾命中与建筑命中使用不同光圈、颜色与声音；偷袭的守卫警戒在实际搬运阶段显现。跳过、关闭或刷新都不再发一次请求，也不再发一次奖励。演出使用定时收尾，渲染帧暂停时也可完成交互；跳过与关闭会取消定时器并结束等待。真人目标的损失、保护与单倍率规则保持不变。

## 出现节奏与旧档

完成六步核心引导、海湾达到十块土地后，普通出海可能遇到新故事。距离上次故事至少八竿后，补给航次会进入故事；满十八竿仍未相遇时，之后遇到鱼获或补给航次会安排故事。攻击、偷袭、寻珠、护盾不被该安排覆盖，因此十八竿不是硬性的全事件保底。

间隔按普通出海次数计，不按倍率放大；跨海域共用间隔，换海域不会重置刷新。特殊出海保持原设施效果，不触发故事或积累这个普通出海计数。旧档首次初始化以当前次数作为间隔起点，不补造历史记录。已有旧版海龟／沉船等奇遇继续按原选择和奖励结算，不中途替换。

## 选择、费用与风险

第一步选择调查、援助或离开。调查支付本海域旧奇遇对应的金币准备费，援助支付对应鱼宠粮。准备之后才选择具体航路；第二步不再收费，关闭与刷新仍保留已付资源和当前阶段。余额不足会在扣款前拒绝，玩家可用另一条准备路线或免费离开。

| 路线 | 结果 |
| --- | --- |
| 调查 → 稳妥修复 | 确定获得该海域基础物资包 |
| 调查 → 冒险探寻 | 基础失利率 35%；成功获得基础包的 1.6 倍向上取整，失利仍获得一半向下取整、每项至少一份 |
| 援助 → 护送伙伴 | 获得 4–6 次钓鱼补给与该海域纪念章 |
| 援助 → 协助整理 | 获得基础物资量的 75% 向上取整、至少三份，以及该海域纪念章 |
| 相遇时离开 | 不支付准备费，获得一次钓鱼补给，不记录印记 |

探寻的随机值在相遇时由服务端保存，并从公开存档移除。失败率由相遇时的探索加成降低，最多降低十五个百分点，最低 20%；界面同时显示成功回报、失利率与失利保底。之后更换伙伴、关闭或刷新不会改变这一段的风险或随机值。探索伙伴名称和降低后的风险在故事里显示，鱼宠说明也包含这一用途。

故事回报不随钓鱼倍率放大；UI 在选择前说明。准备阶段不发船长经验、航程或每日订单进度；真正归航时才结算一次：八经验、原有事件航程与海上见闻订单。旧事件编号、错误阶段、其他路线和重复完成都不能重复扣费或发奖，传输重试沿用原请求编号幂等。

## 数值对照

`node scripts/loop-balance-v17.mjs` 生成 [BALANCE_V017.json](BALANCE_V017.json)。两个进度阶段、四种故事选择策略、各八个固定种子，十四天每天两段各四十竿，共六十四组。所有策略采用相同的设施、航海与外观／养护消费规则，没有随行伙伴；一个阶段只建设第一岛，另一个预设全图与满级设施，不代表自然通关时长。

所有组完成 1,120 竿。选择护送的第一岛场景共完成 61–67 段故事，支付 122–134 鱼宠粮、获得 244–268 次补给；满级场景为 64–69 段、320–345 鱼宠粮、384–414 次补给。该策略未遇到资源不足阻塞，但模拟不代表真实玩家愿意如此选择，也不证明留存或最终经济平衡。

调整时发现沿用旧援助奖励会使高频故事返还过多次数，因而新故事护送奖励收至 4–6 次；保存中的旧奇遇仍使用旧奖励。关闭故事和反复看手记没有额外资源来源。

## 验证与边界

规则检查覆盖十二段数据、出现间隔与新手优先、旧档初始化、准备阶段零完成奖励、失败扣费原子性、进度重放拒绝、风险隐藏与快照、伙伴减风险、三种印记与重复回报、分海域章节交替、历史长度上限、真实响应前不咬钩、六种场景几何体。

浏览器专项检查实际慢请求、实际收费后关闭与刷新、固定风险和保底、重放请求防重奖、援助的资源选择、三种竖屏尺寸、减少动态效果与跳过、真实海域切换。其余原流程继续回归。

场景仍使用程序化美术；十二段属于可重复的有分支海上短篇，不是无限新剧情或完整赛季。未完成实体手机 GPU／发热测试，也没有把自动化和模拟写成真人体验反馈。
