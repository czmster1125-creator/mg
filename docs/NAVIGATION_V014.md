# 0.14 任务与入口

每天要做的事直接展示，常用玩法跟随所在页面，低频偏好留在设置。保留海岛、钓鱼、鱼缸三个主入口。

资源栏下方现在是可点击的“每日订单”卡。它直接展示捕获鱼数、海上事件或建设培养目标，包含实际计数、进度条与奖励。可领奖订单优先；无可领奖时，钓鱼页优先展示鱼获订单，海岛／鱼缸优先展示建设培养订单，已领取的订单不再占首位。全部领取后明确显示今日完成，第二天由现有服务端日期结算重置。

原顶部小礼物移除，订单卡最小高度 60 像素。卡片旁的“任务”打开任务手帐：主线章节及各条件进度在前，每日／每周委托随后，新手航程或成长建议放在下方。主线／周委托可领奖时，任务入口显示“可领奖”。不将鱼宠的可选配置当作全局最重要的行动。

| 内容 | 当前入口 |
| --- | --- |
| 每日订单 | 三页的明确目标卡，一次点击查看全部订单及领奖 |
| 主线、新手、成长目标、每周委托 | 目标卡旁的“任务”；海岛另保留故事入口 |
| 船长经验与升级补给 | 点击船长称号和经验栏 |
| 装备升级 | 钓鱼页的装备入口 |
| 好鱼挑战开关、收线练习 | 装备页上方的“钓鱼偏好与收线练习” |
| 海域选择 | 钓鱼页左侧海域名称 |
| 群岛航线 | 海岛名称；也可由扩张完成后的主按钮前往 |
| 防守、战报、维修线索 | 海岛底部护盾／防守入口与建筑详情 |
| 地标布置 | 海岛底部“布置”；不足 10 块时锁定 |
| 随行、喂养、加成与收藏奖励 | 鱼缸内的伙伴位、鱼卡和收藏入口 |
| 声音、账号与好友、安装、帮助 | 右上角“设置”；账号与好友亦可点头像 |
| NPC 偷袭教学 | 设置 → 玩法帮助 → 偷袭教学 |

“设置随行鱼宠”不再在海岛与钓鱼页常驻。鱼缸内仍显示温和的局部提示，点击可滚动到鱼卡；新手步骤保留在任务手帐，既有进度、奖励和服务端引导顺序不变。已经选择伙伴的玩家继续沿用既有加成，入口调整不取消已配置伙伴。

点击每日订单只打开详情，不会误领或替玩家消耗资源；领奖、建造、培养和钓鱼仍通过原服务端事务执行。短按钓一次／长按自动／再点停止及事件暂停沿用 0.13。
