# 0.18 十二格寻珠、成长护盾与海上互动

本轮对应三项需求：寻珠十二格及 5／4／3 图案分布、护盾数量外显和随等级扩容、增加有实际操作的随机事件。继续沿用海岛、钓鱼、鱼缸三个主页面。

## 十二格潮汐寻珠

寻珠使用四列三排共十二枚贝壳：大奖月光珍珠五枚、中等奖海岛补给四枚、小等奖漂流金币三枚。仍是先集齐三个相同图案就获得一档奖励，继续翻壳不扣钓鱼次数。三档奖励上显示各自场内枚数，以及集齐三个所需的进度。

服务端一次生成并保存完整布局，公开状态不返回未翻开的图案。重复格子、非法格子、已经完成的事件不能再翻或再领奖。图案分布不表示中奖概率直接是 5/12、4/12、3/12：在不使用伙伴线索、完全随机翻选的情况下，先集齐大奖三枚的概率约为 57.03%，中等奖约为 31.39%，小等奖约为 11.58%。伙伴线索会影响实际选择策略。

仍只有三类图案，所以最迟第七次翻开时一定有三枚相同；不需要把十二枚全部翻完。奖励金额、倍率与伙伴加成继续使用相遇时的快照，没有因为改成十二格重新收费或改写已保存的奖励。

旧版九格进行中的局会一次性补入三枚未打开贝壳，两枚大奖、一枚中等奖。原九个格子编号与图案、已翻记录、伙伴线索和奖励快照均保留，不重新洗掉玩家的进度。更早的六格三次挖掘旧局继续原结算。

## 护盾外显与成长

三个主页的顶部资源栏常驻显示护盾“当前／容量”，点击进入防守说明。海岛防守入口、事件结果与船长成长页使用同一容量规则。

| 船长等级 | 容量 |
| --- | --- |
| Lv.1–4 | 3 |
| Lv.5–9 | 4 |
| Lv.10–19 | 5 |
| Lv.20–34 | 6 |
| Lv.35–49 | 7 |
| Lv.50 及以上 | 8 |

升级只扩容，不自动补满；钓到守护贝壳补一层，满盾继续转为两次钓鱼补给，倍率不把一层盾变成多层。受袭与演习每次消耗一层，容量不因此下降。船长页列出各档，防守页显示下一扩容等级。玩家护盾与 NPC 对手的护盾仍分别保存，真人互访保护沿用原规则。

## 随机事件的结构与节奏

原有攻击、偷袭、寻珠之外，增加两种操作型事件。完成核心引导、海湾扩张五块后，普通出海的基础抽取中各占 4%，合计 8%，从原鱼获区间拆出；攻击、偷袭、寻珠、护盾和补给的原基础区间不变。成熟阶段、未触发额外故事安排与久未遇事件保障时，基础鱼获由 52% 变成 44%。

两种新互动连续抽到同一类型时会换成另一类型，减少重复。新手引导中的指定事件保持优先，特殊出海继续履行设施承诺。原有海上故事也保留，因此这里的基础区间不是所有玩家长期经历的精确比例。

自动钓鱼遇到新事件会暂停；玩家完成操作或提前归航后再选择是否继续。新事件不增加主 Tab，也不额外收取钓鱼次数。关闭和刷新会保存货舱、路线与进度。

## 漂流箱打捞

六个漂流箱展示不同的金币、物资或鱼宠粮，可以从船锚拖出绳子落到箱子上，也可直接点击箱子。每趟最多选三箱，选择会保存在未入账货舱，第三箱后一起归航入账。

箱子组合固定为六种资源包，位置随机洗牌。玩家选择的是这一趟需要的资源，箱中内容不会在点击后临时改变。货舱奖励随原钓鱼倍率放大，选择本身不另扣次数。

可以提前归航，带回已经选中的资源；一箱也没选时只获得 `1 物资 × 倍率`。拖动取消、落在箱子外、重复箱子、错误行动序号与伪造事件编号均不能推进或发奖。

## 海龟护航

护航使用三排、每排三个浮标。可以拖动海龟，也可点击下一排相邻浮标；只能在相邻水道间移动，不能跳排或横跨两列。三种节点事先可见：

| 节点 | 本段效果 |
| --- | --- |
| 平稳水道 | 暂存一份海岛物资 |
| 海草浮标 | 暂存一份鱼宠粮 |
| 急流水道 | 暂存三十金币，安全值减一 |

初始三个安全值。成功走完三排，会获得沿途货舱，另加三次钓鱼与两份海岛物资。连续走过三处急流会耗尽安全值，此时沿途暂存货舱替换为一份鱼宠粮和一次钓鱼的返航保底；已有钱包不受损失。提前归航同样只领取该小额补给。

护航奖励固定、不随钓鱼倍率放大；UI 在选择前说明，避免把更多次数投入当成更多护航返还。路径、节点和安全值都在服务端确认，每一步会保存，重复或非法路线不能追加暂存。

## 结算与验证边界

中间操作不发船长经验、每日订单完成或事件航程；完成或提前归航才结算一次，经验使用原海上奇遇的八点，事件航程按原投入倍率记分。服务端保留原请求编号幂等，网络重试不能再领一份。

`node scripts/loop-balance-v18.mjs` 生成 [BALANCE_V018.json](BALANCE_V018.json)。两个进度阶段、两种互动策略各八个固定种子，十四天每天两段各四十竿，共三十二组。两个策略分别提前归航，或实际挑三箱并走安全护航路线；其他设施、航海与外观消费规则一致，海上叙事故事均选择离开。所有组完成 1,120 竿。

第一岛参与互动的策略完成 69–86 趟新互动；满级预设场景为 73–103 趟。这个结果说明该固定策略可以运行，不能证明玩家更喜欢这些操作、经济已经最终平衡，或真机性能已通过。

目前仍使用触屏模拟与软件 WebGL 验证，真实设备体验与留存需要后续试玩。没有增加真实支付、广告、排行榜或新的强制日常任务。
