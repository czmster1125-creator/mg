# 0.7 按顺序补齐的四段内容

本版依次落实独立 NPC 偷袭、鱼宠特色能力、场景与攻击演出、每日订单与经济检查。底部仍为海岛／钓鱼／鱼缸，保留原存档的资源、土地、鱼种与等级。

## 1. 独立偷袭

速钓自由概率调整为鱼获 52%、攻击 12%、偷袭 10%、寻宝 12%、护盾 8%、补给 6%。连续九次没有攻击／偷袭／寻宝时，下一次保证其中一种；新手八步仍使用原引导结果。手动搏鱼仍只产生鱼获。

钓到夜航罗盘后，先查看 NPC 储金岛、登岛，再决定搬运路线。与攻击建筑、选格寻宝分别独立：

| 路线 | 基础可搬金币 | 初次被发现概率 |
| --- | ---: | ---: |
| 海边货栈 | 45 | 0% |
| 码头仓库 | 95 | 24% |
| 银行金库 | 165 | 48% |

每次偷袭最多行动三次，可随时提前撤离。第二／三次冒险路线风险分别增加 10／20 个百分点；稳妥路线仍为零基础风险。潜行鱼宠增加搬运金额并降低风险，事件开始时锁定加成，不能临时换宠物改结果。

搬出的金币先进入未到账赃物，撤离或三次行动完成后统一入账。被发现时保住此前赃物的一半，其余退回 NPC；不扣已有钱包、不损失土地／宠物。NPC 基础金库初始 1,800，每次抛竿恢复 10、最多 1,800。倍率同时放大本次可见金库与搬运金额，最终按基础金额扣减 NPC 金库，金库不会出现负数。

事件、行动和风险抽签保存在服务端，未揭晓抽签不会发送客户端；关闭或刷新后继续。海岛提供一次消耗 1 鱼饵的潜行教学，完成后无法反复领取。所有角色均明确为 NPC，尚无真人资产转移、好友或复仇匹配。

## 2. 十二鱼种的特色能力

| 鱼宠 | 定位／特色 |
| --- | --- |
| 小丑鱼 | 经营：稳定提高鱼获与银行金币 |
| 蓝倒吊 | 攻击：攻击力与破盾金币补偿 |
| 银色沙丁鱼 | 探索：寻宝金币与大奖线索 |
| 珊瑚蝶鱼 | 经营：普通金币加成之外，额外强化银行 |
| 翡翠鹦嘴鱼 | 潜行：提高偷袭收益，隐蔽成长更强 |
| 皇家神仙鱼 | 探索：寻宝金币、线索与宝藏宠物粮 |
| 黄金翻车鱼 | 经营：金币与补给宠物粮 |
| 红鳍笛鲷 | 经营：金币和少量偷袭收益 |
| 斑纹石斑 | 攻击：攻击力与维修折扣 |
| 蓝鳍金枪鱼 | 攻击：较高的每级攻击成长 |
| 月光蝠鲼 | 潜行：搬运收益与隐蔽兼顾 |
| 星海旗鱼 | 潜行：搬运成长更高，隐蔽成长较低 |

技能名称、当前数值及下一级预览在鱼宠详情展示，实际应用于对应服务端结算。仍最多三个随行位、每定位一只，现在四种定位需要取舍；宠物粮升到十级共消耗 135，每级费用保持当前等级 ×3。全队加成设上限，未实现独立技能树或进化分支。

## 3. 海岛与演出

海岛镜头根据已开放土地与相邻选择调整范围；增加建筑前步道、居民散步、花坛、港口货箱与浮动产出／损伤标记。第二地区采用港口地面与海色，复用六边形拓展骨架，尚不是完全不同的手工地图。

攻击结果增加 3D 目标晃动、碎片和击破后的模型变化，显示实际奖励。偷袭使用夜色储金岛与未到账金额面板；撤离给予归航反馈。上述均为程序化模型与效果，没有提取参考游戏资源。

## 4. 每日订单与经济验证

每日北京时间 00:00 更新，三条订单：捕获八条鱼、完成三次海上事件、扩张／建筑升级／培养共两次。只统计当天真实动作，不追溯旧存档历史；每单手动领取一次。全部完成共奖励 290 金币、20 鱼饵、2 宠物粮、2 零件与2 建材。重试同一请求不会重复发放；时间回拨不会重置已领取状态。

运行 `npm run balance` 可复现经济检查。原始数据见 `BALANCE_V07.json`：20 个固定随机种子，三段各最多 60 次速钓，间隔一小时，倍率一，稳妥偷袭、攻击银行、优先扩张、领取订单，不装备宠物、不升级银行。

该策略首段 60 竿（约十二分钟）能扩张第一岛 23–25 块；20 组均完成 180 次抛竿，没有中途断饵。建设里程碑的一次性补给使 Demo 前期鱼饵偏充足，首岛推进偏快。这个结果是固定策略模拟，不是留存或正式平衡验收；正式长线版本应继续验证消耗优先级、扩张速度和内容量。

银行正常状态的四次升级静态回本为 4／5／6／6.25 小时；本轮保留银行数值。第二岛继续消耗金币与功能土地建材；鱼宠培养提供宠物粮消耗。暂未添加付费资源、广告、签到包装或赛季。
