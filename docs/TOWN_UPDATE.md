# 海岛建设与 3D 基地（0.3）

## 解决的问题

旧版在地标等级为 0 时已经生成完整房子；升到 1 级只改变少量高度，且多数地标共用小屋外形。基地仅提供列表弹窗。此次改成可辨识的建造阶段和独立的基地场景模式。

- 两个区域的 0 级地标显示低矮施工地块，首次建造生成完整主体。
- 每个地标的 1–5 级改变实际几何结构：门廊、二层、侧翼、塔楼、吊机、围栏、花园等按建筑类型添加。灯塔逐渐增高，码头从木栈桥发展出棚屋、吊机和货场。
- 建造后替换对应模型并播放短促弹起和落成粒子；其他地块不重建。刷新、切换地区与返回海岛都从服务端存档恢复。
- “建造 / 升级地标”优先选择最低等级地块，避免持续升级第一座建筑而留下其他空地。

## 基地的空间与操作

五座生产建筑直接展示在 3D 小镇中，并拥有不同轮廓：

| 建筑 | 模型特征 | 原有产出 |
| --- | --- | --- |
| 渔业总部 | 紫色屋顶、塔楼与旗帜 | 自动恢复鱼饵 |
| 海岛银行 | 柱廊、金币标志与金库扩建 | 金币 |
| 钓具工坊 | 青绿屋顶、烟囱与旋转水轮 | 零件 |
| 海风集市 | 条纹遮阳棚、货架与货箱 | 建材 |
| 宠物乐园 | 粉色小屋、围栏与活动设施 | 宠物粮 |

道路将建筑连接到喷泉与码头，外围有树木、花圃、长椅、路灯与小摊。居民沿主路行走，装饰小狗在乐园附近活动。拖动可轻微旋转视角，归位按钮恢复默认构图。

点建筑本体或名称标签打开底部详情，显示当前等级、下一阶段、产出变化与金币费用。详情保持主场景可见。金币不足或满级会禁用升级；交易仍由原服务端校验。

收益气泡附着在建筑附近，并避开名称触控区；狭小空间下收起部分气泡，底部始终显示全部产出并提供统一领取。**任意收益气泡与底部领取按钮都领取全部可领取收益**，沿用原有一次性事务。总部鱼饵自动恢复，不生成手动领取气泡。气泡图标轻微浮动，点击热区保持固定。

## 兼容性与实现

经济、价格、产出、离线时长及存档字段未改动。建筑模型按模式、地区、等级缓存；仅等级或场景变化时替换。海岛和基地共享一个渲染器，避免来回导航创建更多 WebGL 上下文。静态几何体按材质合并，移动水轮保留独立节点，阴影在建筑变化后更新。

模型合并统一索引格式，并验证包围盒与射线命中不变，防止优化时遗漏屋顶。首帧时间差限制为非负值，避免首次创建大型场景时居民路径出现负参数。

基地是新的可交互 3D 场景，但道路布局仍与海岛共用，居民与小狗是装饰动画。没有新增宠物养成或居民经济系统，也没有复制参考截图的品牌与素材。真实手机性能和微信适配仍需单独验收。
