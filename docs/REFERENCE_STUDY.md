# 竖屏钓场改版：视频观察与实现范围

参考：用户提供的 `bandicam 2026-11-06 18-26-15-066.mp4`（96.733 秒，528×996，30 fps）。分析采用每 5 秒抽帧，以及 29–43 秒、54–62 秒每秒 2 帧的加密抽样；没有声称逐帧看完全部视频。最初上传的 `20261013-163339.mp4` 超过文件工具 32 MiB 限制，未读取；本次改版依据随后成功读取的录屏。

## 直接观察

- 约 5–20 秒：纵向蓝色水道、两侧岸线，顶部等级与委托条，底部功能入口。钓点是水面圆环，不依赖多个大文字卡片。
- 约 33–42 秒：小艇在圆环附近转向，鱼竿与线连接到钓点；圆环局部进度、上鱼水花、鱼获弹出构成清楚的反馈链。
- 约 30–38、60–66 秒：鱼获独立展示，模型突出，伴随彩纸、品质与价值。随后返回原钓场。
- 约 54–62 秒：装备和图鉴为独立面板，不持续覆盖核心水面。

录屏中没有可辨识的触摸点。仅凭画面无法确认原作使用了摇杆、拖动还是自动寻路，也不能确认其他船只是否是真人。此次没有伪造多人在线功能。

## 本次实现

- 所有屏幕统一为竖屏玩法。手机填满视口；电脑显示居中的 9:16 游戏画框，不再展开成桌面侧栏布局。
- 钓鱼场景改为纵向水道，两侧棕榈、岸石、码头和灯塔形成边界。海岛建设保留独立地图视图。
- 三个钓点改成可点击的大圆形透明热区、水纹和游动鱼群。仅选中点有小鱼标记，描述集中在下方一处显示。
- 点击／拖动水面驾船；点击鱼群自动驶近。船体有转向、加减速、轻微侧倾和尾迹；移动本身不消耗鱼饵。开始钓鱼时先到达可抛竿位置。
- 抛竿飞行弧线、鱼漂入水、弯曲鱼线、圆环进度、水花、鱼跃入舱串成连续动作。
- 手动挑战改为场景底部的小面板，中央水面保持可见。按住蓄力、松开抛竿、上钩提示、张力与进度并排展示。
- 鱼获结算增加可旋转的 3D 鱼模型与彩纸；关闭时释放其 WebGL 资源。
- 静态岸线按材质合并、缓存静态阴影、复用水花粒子；慢帧时自动降低渲染分辨率。手动进度按实际输入时间结算，不按帧数累计。

## 差异与未实现内容

保留原项目的热带海岛主题与已有经济规则，没有复制视频的冰雪资源、其他玩家、原游戏品牌或 UI 资产。保留显式抛竿按钮，没有擅自改为持续自动扣饵。此次是对视频界面组织和动作反馈的重制，不是对原作联网系统的逐项复制。实体手机性能与微信小游戏适配仍需后续验证。
