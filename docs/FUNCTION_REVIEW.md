# 0.4 功能梳理与后续优先级

## 本轮已经落地

底部固定为「海岛、钓鱼、图鉴、基地」，默认仍进入钓鱼。移除鱼舱入口、库存上限、锁鱼和出售操作；速钓与手动成功捕获均由服务端直接结算金币，图鉴继续保留鱼种、次数和最大重量。旧鱼舱中全部鱼获（含锁定鱼）在首次读取时一次性折价，图鉴不变；旧出售委托改为捕获并结算，避免断档。

海岛使用六边形土地：7 块初始土地、每区域 25 块可扩张土地。只有与已有土地相邻的蓝色加号可以购买；购买后变为草地、增加景观并露出新的相邻选择。每 5 次扩张升级中央小屋并保留原建设奖励，完成 25 次开放下一区域。已有建设点按数量映射为连续土地，不重收费用。旧的任意建筑升级接口停止使用，不能绕过相邻规则。

基地继续负责离线生产和建筑升级，海岛负责土地扩张与景观成长。参考图片的格子扩张组织方式，不包含动物园、水族馆或参考游戏素材。

## 当前循环是否合理

钓鱼 → 金币与图鉴 → 扩张海岛／升级基地与装备 → 补给与成长 → 再钓鱼。这条循环可玩，四个入口的职责也比较明确。取消鱼舱减少了频繁出售的打断，但同时失去了“留鱼”决策，应由图鉴目标、特殊鱼用途或订单在后续承担，而不必重新加回仓库。

## 可核对的经济观察

- 第一区域 25 格总金币成本为 `5 × (80 + 120 + 180 + 260 + 360) = 5,000`；第二区域为 10,000。
- 第一区域里程碑累计额外发放 130 鱼饵。奖励会显著补充下一轮钓鱼，因此不能只按初始 40 鱼饵判断推进速度。
- 基础银行每升一级增加 12 金币／小时；升级费用 80/320/720/1,280，对应新增产出的静态回本时间约 6.7/26.7/60/106.7 小时。高等级不适合靠“提高效率”吸引短期 Demo 玩家。
- 基础总部每小时恢复 5 鱼饵，空仓恢复到 50 需要 10 小时；需要结合预期单次游玩时长决定是否增加免费补给。
- 倍率 ×2/×5 目前是独立多次结算，主要节省点击时间，不提供更高单位收益；UI 不应暗示它提高稀有概率。

以上是配置推导，不是真实用户留存或商业化测试结果。

## 建议下一轮的范围

先补齐“前 10 分钟引导 + 5/10/15 格解锁奖励 + 图鉴章节奖励 + 建材消耗”，再打磨手动钓鱼的鱼种差异。以玩家能否理解下一步目标、首块扩张耗时、连续游玩是否断饵、各升级的实际价值作为验收指标。暂不扩大宠物、活动、广告和社交系统。
