# 0.8 缺口补齐与真实边界

本版目标平台是手机浏览器与可安装网页版。保留原有角色存档，增加真实账号／玩家互访、长线章节／专精／地标、区域场景差异、服务端输入校验与安装离线支持。没有使用虚构玩家冒充真实联网。

## 账号与真实互动

点击左上船长头像进入账号／好友面板。账号使用 3–20 位英文数字下划线、10–128 位密码。注册将当前角色绑定账号，登录同一服务器可跨浏览器继续；密码使用随机盐与 scrypt，登录 Cookie 轮换，数据库只存会话令牌摘要。绑定后旧游客 Cookie 不再能访问该账号。恢复密钥只显示一次，重设密码会轮换密钥并撤销旧会话，登录后也可用当前密码重新生成恢复密钥。无邮件或短信找回，恢复依赖玩家保存密钥；服务端需保留并备份数据库。

好友码需对方接受；互访须双方绑定账号、自愿加入、各自捕获三条鱼并扩张一块土地。可以指定好友、随机寻找实际注册玩家或对七天内的一次受袭记录复仇。加入后倍率一的攻击／偷袭漂流事件优先尝试真实目标，无可用目标时保留 NPC；其他倍率保持 NPC，界面明确区分。

真人攻击消耗护盾或损坏已开放建筑；最多同时损伤两座，不降等级、不收土地。成功造成新损伤获得 25 金币系统奖励；被挡或无新增损伤不发奖励。该奖励不从对方钱包扣除。

真人偷袭开始时从目标钱包暂存最多 10%、上限 250 金币；按已有潜行风险规则结算，实际偷到部分给攻击者，其余退还目标。双方钱包、事件与发奖幂等记录在同一 SQLite 事务内提交。关闭／刷新保留事件；超过 24 小时未结算会全额退回并清理事件。目标离线也可接收真实玩家行为，重新登录查看战报／复仇。退出互访停止新的匹配，已经开始的访问仍结算。

同一对手五分钟一次、目标每天最多接待三次、新手／维修保护限制持续骚扰。没有额外伪造的在线人数或机器人好友。

## 长线内容、技能与资源消耗

五章连续海岛故事，覆盖捕鱼、土地、攻击、偷袭、寻宝、跨海域收集、建筑等级与宠物培养；达成后手动领取一次，不追溯发放未存在的事件历史。章节条件中已有鱼种、土地、等级直接识别，新增事件计数从本版开始。

鱼宠达到五级后可选择专精，消耗 8 零件＋3 建材：精打细算提升本宠效果 15%；稳健伙伴提升 10% 并附加三点隐蔽。选择后固定，已有全队上限仍生效。每座岛扩张十块后可三次布置永久地标，每级消耗 150×等级金币、3×等级建材，提供长期展示与消耗目标。

海域奇遇在十块土地后、补给事件的特定航次出现：海湾沉船或珊瑚海龟。可以花金币打捞零件／建材、花宠物粮救援换鱼饵与永久纪念章，或直接离开。事件会保存。另有每六小时一次、仅空饵时可领的五鱼饵应急补给，避免完全卡住。

未来地块价格调整为 80／140／220／320／440，第二岛乘二；已买土地不补扣。每五块的一次性鱼饵改为 10／10／10／10／30；已有奖励不追回。银行费用、产出和回本关系保留。

`BALANCE_V08.json` 与 `npm run balance` 记录 20 种固定种子，用与 0.7 相同的扩张优先策略作对照，不计算专精／章节／地标消费；该模型不是实际用户留存。服务端保存玩法金币收入、支出和速钓次数计数，供后续针对真实试玩反馈调整，不能用程序模拟代替长期用户数据。

## 场景与手机端

海湾有绿地、棕榈、山体、瀑布及凉亭；渔港采用不同纵横比例的地块投影，有长栈桥、吊机、泊船、货场和港口建筑附加结构，升级地标形成不同景观。逻辑仍使用相邻六边形扩张，不改变旧土地归属。

网页提供 manifest、192／512 安装图标、主屏幕入口；HTTPS 或 localhost 环境可启用 Service Worker。静态壳与已访问资源缓存，API 与交易不离线缓存。断网时阻止抛竿并提示，联网后从服务端恢复；没有承诺离线游玩或离线发奖。iPhone 使用 Safari 分享菜单添加到主屏幕，浏览器是否显示自动安装提示由平台决定。生产 Cookie 可通过 `COOKIE_SECURE=1` 限制 HTTPS。

手动挑战改为服务端回放按住／松开时序；直接提交成功无法发奖。服务端验证事件、时序长度、耗时与物理规则，仍不能阻止遵守输入规则的自动化脚本；这属于基础防篡改，不能称为已完成商业化反作弊审计。

## 交付验收不冒充完成的部分

代码和模拟器可验证功能、交易及触屏事件。实体 iPhone／Android 的 GPU 帧率、热量、浏览器安装体验，以及真实用户长线经济曲线，必须用设备和试玩数据实测；本环境没有实体手机，不会把软件 WebGL 的结果标为真机验收。当前没有对公网发布服务器，真实互动限定连接同一服务实例的玩家。
