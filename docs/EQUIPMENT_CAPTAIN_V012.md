# 0.12 装备、船长成长与海岛交互

## 三件装备

装备为潮汐钓竿、贝光鱼钩、航海罗盘，各有十个强化等级。0 级已有基础能力；每次强化消耗下一等级 ×80 金币、下一等级 ×2 海岛物资。5／10 级获得精制／星辉视觉阶段，罗盘另有物资节点。所有旧鱼种、海域和已发现鱼宠继续保留，不新增品质等级门槛。

| 装备 | 实际效果 | 生效范围 |
| --- | --- | --- |
| 潮汐钓竿 | 每级幸运使稀有、史诗的基础权重提高 6%，再将四档权重归一化；操控每级降低 8% 张力增长，最多降低 40% | 自动收获与挑战均使用幸运；操控作用于挑战 |
| 贝光鱼钩 | 每级给体型抽取位置增加 0.025 偏移，封顶在该鱼种正常体重上限；售价使用实际重量 | 自动、手动、整批暂存与保底收获 |
| 航海罗盘 | 每级提高寻珠金币 3%；5／10 级各增加 ×倍率的一份寻珠、普通补给物资 | 寻珠与普通补给，不改变攻击、偷袭、护盾触发率 |

钓竿详情提供三个钓点的当前／升级后四档概率，界面与实际选择共用 `shared/equipment.js`。这些是抽到“鱼获”后的条件概率，不包含海上事件；新发现保底可覆盖品质抽取，倍率不增加概率。鱼钩不叠加独立鱼价倍率；罗盘与鱼宠对寻珠的实际奖励统一由 `treasurePrizes` 计算，在事件创建时锁定。

### 旧装备迁移

`gearVersion:2` 只迁移一次。新钓竿取旧钓竿、旧鱼饵等级的较高值；两者重叠等级的金币与物资投入退还。鱼钩免费继承旧护符等级，并全额退回旧护符强化投入，补偿机制改为体型收益。罗盘从基础级开始。

旧等级 L 的总投入为 40×L×(L+1) 金币、L×(L+1) 物资。例：旧等级 `[2,3,4]` 转为 `[3,4,0]`，退还 1040 金币、26 物资。库存、海岛、鱼宠、船长经验不清零。已开始的旧挑战继续使用创建时保存的操控参数和鱼获。

## 船长经验与称号

每 100 经验升一级，保留全部已有经验。点击船长称号或手记内“船长成长”，可以看到本级进度、下一称号、经验来源和升级补给。头像仍用于账号与好友。

| 行动 | 经验 |
| --- | ---: |
| 捕获一条鱼 | 5 |
| 首次发现该鱼种，额外 | 10 |
| 扩张一块土地 | 15 |
| 升级建筑／装备 | 10 |
| 喂养一次鱼宠 | 5 |
| 完成攻击／偷袭／寻珠 | 12 |
| 完成海上奇遇 | 8 |
| 领取日订单／收藏 | 10 |
| 完成故事章节 | 25 |
| 领取周委托 | 20 |

鱼宠专精和地标布置另各加 10 经验。旧委托直接列出的经验奖励仍额外发放。挂机领取、维修、事件进入、中途搬运和单纯重复点击不增加经验。鱼获在真正收获时计数，保底和超时不会重复计入；真人攻击由同一经验规则结算。

称号节点为 Lv.1 见习船长、Lv.5 海湾船长、Lv.10 逐浪船长、Lv.20 群岛领航员、Lv.35 远洋领航员、Lv.50 星海船长。等级记录冒险成长；新海域仍由海岛建设开放，避免增加第二层硬门槛。

2—50 级每级可领取 30 金币、3 鱼饵；每逢五级另加 2 物资、1 鱼宠粮。旧玩家已经达到的等级可以补领一次，领取补给本身不增加经验，最高补给等级为 50。未回算已经完成的历史行动经验，也不扣减已有经验。

## 报错修复与交互演出

首次钓到偷袭的响应是 `{type:'raid',event:true}`，旧界面却把所有 `type:'raid'` 都当作已结算结果。结果页没有入场场景容器，后续创建 Three.js 场景时对空容器调用 `append`，触发用户截图错误。

现在按进入／行动／结算分流，只有实际结算且存在金币结果时才渲染返航页；每个偷袭阶段都有自己的场景容器。渲染器在创建前检查容器，缺少 WebGL 时保留可操作的文字／按钮界面。异步行动期间关闭页面会销毁场景并结束过场等待，已保存的结果不会在关闭后强制重新弹出。

攻击和偷袭使用独立的全屏登岛界面，包含可点击的 3D 建筑、船只、玩家角色和对手角色：

- 攻击：选择建筑、椰果投掷、飞行轨迹、护盾闪光或建筑受击、角色反应和结算。
- 偷袭：小艇靠岸、角色登岛、守卫巡逻与灯光、靠近货箱、搬运、警报或安全撤离。
- 岛上建筑和下方按钮都可操作；动效可跳过，系统减少动态效果偏好下直接展示结果。
- 服务器先确认行动，客户端再播放演出；动画、跳过、关闭和重开不会再次扣饵或发奖。中途搬运仍未入账，撤离时才入账。

四位 NPC 为灰帆船长莫洛、贝壳商人米娅、海风船长阿洛、星湾舵手露娜。每位保存独立护盾、建筑损伤和金库，攻击／偷袭完成后轮换；每次抛竿恢复各 NPC 金库 10 金币，上限 1800。已开始的目标固定，刷新不重选。清楚标注 NPC，不冒充真人。真人互访仍按既有暂存、退款和受损保护规则运行，不增加真实玩家损失。

“归位”入口及其点击处理已移除。发布构建按产物指纹生成安装版缓存名，避免仅改界面却继续缓存旧包；入口与服务脚本使用禁止陈旧复用的缓存策略，账号和服务器存档不依赖该缓存。

验证脚本与截图位于 `scripts/capture-v12.mjs`、`docs/screenshots/equipment-v12/`。录屏使用可用的 FFmpeg；其他机器可通过 `npx playwright install ffmpeg` 准备录制依赖。截图使用独立展示数据库；首次偷袭入口复现由真实 `raid/start` 存档响应转发到钓鱼响应边界，后续登岛、搬运和撤离走真实 API，不修改试玩数据库。
