# Tidebloom 落海开场与新手流程方案 V2.0

日期：2026-11-13。状态：流程设计建议稿，未改动当前 0.18 游戏代码。

本方案采用“飞机故障 → 顺利跳伞 → 木板漂流 → 在浅礁立足 → 金币不足 → 钓鱼交易 → 返回扩张 → 建成家园”的开场。现有海岛、钓鱼、鱼缸三个主页，以及鱼宠、寻珠、护盾和 NPC 互动继续保留，调整教学顺序和新账号初始状态。

## 一、首局需要让玩家理解什么

首局最重要的认知是：钓鱼能换来金币，金币能让自己的家园长大。

完成第一轮后，玩家应能回答三个问题：下一块地要多少钱；金币从哪里来；攒够后回哪里建设。首次鱼宠、装备、攻击和多种日常目标逐步介绍，避免它们抢走这条主线。

推荐把“建成五块家园”作为核心引导的结束点。之后的功能教学使用独立进度，不要求玩家先完成攻击、寻珠或喂养，才算理解游戏。

## 二、开场叙事与世界观

### 飞机故障

建议使用单人小飞机，以轻喜剧方式处理故障。主角顺利跳伞并抱住木板，明确表现已经脱离危险。剧情目标尽快转为安顿与建设，不引入持续饥饿、伤势或氧气等生存资源。

镜头建议：云层中的飞机故障 2–3 秒 → 主角打开降落伞 2–3 秒 → 落海、抱住木板 3–4 秒 → 镜头落到可操作的浅礁区。总长约 10–15 秒作为制作目标，实际需看素材与设备测试。

可以保留一次“拉开降落伞”的点击，让玩家参与；应无失败惩罚，并提供跳过动画。跳过直接进入安全的木板与浅礁画面，不多发一份开场物资。

### 木板与浅礁

木板漂到一片浅礁旁。救生包里有少量金币、简易鱼竿与鱼饵。第一块扩张表现为加固浅礁、铺设落脚平台，再逐渐形成沙地与小岛。

金币支付拓岛施工、物资采购或运输服务。画面给出材料落下、平台拼起、沙地形成的过程，帮助玩家把金币消耗与实际变化联系起来。

初始木板和礁石是临时载具／施工锚点，不计入已建设土地。第一笔购买计为第 1 块建设地。新手开场不先摆好完整岛屿与两栋营业建筑。

### 从遇险转为安家

收鱼人与其他船只出现后，应尽快交代玩家已经处于港湾安全水域、救援联系已恢复。后续通过“暂时歇脚、修好旧码头、照顾路过的伙伴”转为主动经营家园。

需要避免一直强调被困求救，却让商船长期只来收鱼的叙事矛盾。一个简短的过场或对白即可完成转折，不需要另做漫长救援任务链。

## 三、核心引导流程

以下时长为体验目标，非已经实测的玩家数据。预计前 3–5 分钟完成核心循环，阅读、设备和玩家选择会影响实际时长。

| 步骤 | 画面与剧情 | 玩家操作 | 反馈与教学 |
| --- | --- | --- | --- |
| 1. 顺利落海 | 主角抱着木板，救生包浮到身边 | 点击继续或跳过动画 | 明确人已安全，进入可操作画面 |
| 2. 找到落脚处 | 木板靠近浅礁，推荐一块相邻施工区域 | 点击地块，确认花费 80 金币 | 金币 80→0，材料落下，形成第一块可站立区域 |
| 3. 想再扩一块 | 第二块地显示价格、余额和差额 | 点击下一块地 | 展示“需要 80，当前 0，还差 80”，主按钮为“去钓鱼赚金币” |
| 4. 拿起鱼竿 | 救生包中的简易鱼竿、近处鱼群亮起 | 轻触钓鱼图标，或点击教学鱼群 | 自动靠近并抛竿，完成一次无压力收获 |
| 5. 鱼获换金币 | 收鱼船靠近，展示鱼获与本次报价 | 首次点击一次“交付鱼获” | 金币清楚飞入余额；展示这笔交易后足够建设 |
| 6. 带钱回家 | 任务变为“金币已够，扩张第二块” | 点击“返回扩张”，再确认购买 | 新土地与小码头出现，完成第一次闭环 |
| 7. 自己再做一轮 | 给出“把家园扩张到五块”的目标 | 钓鱼、自动结算、攒钱、扩张 | 后续根据余额推荐行动，逐步减少手指与遮罩提示 |
| 8. 家园初成 | 第五块建设完成，小屋、码头与伙伴角落组成小岛 | 点击查看建成效果 | 结算原五格里程碑，核心强引导结束，给出一个近期目标 |

第 3 步不应只弹“金币不足”然后关闭。建设面板应保留明确差额，并把玩家带向可执行的赚钱方式。

第 6 步要保留玩家主动点击返回，帮助建立两个主页的空间关系。金币达到目标时可以暂停教学中的连续钓鱼、提示回家，但不要在鱼获演出中突然强制跳页。

第 7 步按实际余额判断：钱够就推荐建设，钱不够就推荐钓鱼。其他合法奖励让余额足够时，直接推进，不要求玩家再把金币花光。

## 四、首局资源账本

### 推荐的新账号配置

| 项目 | 建议 | 目的 |
| --- | --- | --- |
| 初始金币 | 80 | 恰好支付第一块地，第一次自然出现资金缺口 |
| 前五块建设价格 | 每块 80 | 沿用现有首阶段价格，让学习目标稳定 |
| 初始鱼饵 | 20 次 | 覆盖首轮教学和低售价情形，不用等待恢复 |
| 物资与鱼宠粮 | 前期不作为必需建设门槛 | 首轮只理解次数和金币；其他资源在对应系统开放时介绍 |
| 首单交易 | 固定教学收购价 80 | 保证第一次钓鱼后能立刻体验返回扩张 |
| 后续交易 | 第二、三笔可设教学报价 40、40，再过渡到正常售价 | 用一个容易理解的两次收获目标完成第二轮 |
| 五块里程碑 | 保留现有 10 次鱼饵奖励，其他补给统一核算 | 支持继续探索，避免和旧引导奖励重复发放 |

### 前三块的示例流水

| 行为 | 金币变化 | 余额 |
| --- | --- | --- |
| 打开救生包 | +80 | 80 |
| 建设第 1 块 | −80 | 0 |
| 完成首单鱼获交易 | +80 | 80 |
| 建设第 2 块 | −80 | 0 |
| 后续收获与交易两次 | +40、+40 | 80 |
| 建设第 3 块 | −80 | 0 |

80／40／40 是教学报价方案，不应因此把全游戏鱼价统一改成固定值。鱼种、体型、装备与伙伴对常规收益的作用继续保留。教学报价结束后可出现正常价格波动，但前五块应通过次数预算与鱼池保护避免断档。

以上流水只在其他金币奖励延后或统一合并后成立。现版本初始金币、预置待领收益、每步引导 40 金币、旧委托自动奖励和收藏奖励需要一起核算，不能在同一阶段并行叠加。

不需要把每次扩张都设计成余额归零。首次资金用尽负责建立认知，之后让玩家按自己的收入和选择建设。

## 五、首次卖鱼与鱼宠怎样衔接

推荐首批教学鱼获为两尾同种鱼：留一尾作为第一位伙伴，其余交给收鱼船。首单的 80 金币来自可交易鱼获，不把已留下的伙伴再卖一次。鱼宠解锁和交易各记一次，教程批次不因两尾鱼额外扣两次鱼饵。

第一次交付展示清楚的三个结果：交付了哪些鱼获、获得多少金币、哪位伙伴被留下。伙伴先在临时海水桶中露面，暂时只给一句短提示，不立即跳鱼缸或强制喂养。

之后仍保留“首次发现鱼种可解锁伙伴”的规则。鱼宠是该鱼种的永久培养与展示记录，后续重复鱼获继续按既有规则结算并更新纪录／默契，避免反复做留鱼、卖鱼和整理库存。

只在第一次交易要求点击确认。后续收获自动完成鱼获交付与金币结算，用短动画和文字说明。继续沿用三个主页，不恢复鱼舱、容量、手动出售或独立商店 Tab。

## 六、土地与家园的可见变化

| 建设进度 | 建议画面变化 | 需要介绍的内容 |
| --- | --- | --- |
| 第 1 块 | 浅礁加固、小平台，主角有了落脚处 | 金币可以买来可见建设 |
| 第 2 块 | 沙地延伸，小码头雏形 | 钓鱼赚的钱能再次扩张 |
| 第 3 块 | 潮汐小屋出现，简易小木舟准备好 | 有家后能恢复鱼饵；木板阶段转为自由划船 |
| 第 4 块 | 地形连成片，出现绿化和后续建筑预留区 | 让玩家自行完成一轮，减少讲解 |
| 第 5 块 | 小岛轮廓形成，码头小铺与伙伴角落落成 | 核心引导结束，开始经营与收藏 |
| 后续约第 8 块 | 匠人小屋与物资用途逐步开放 | 再介绍装备、建设物资与更长线投入 |

推荐潮汐小屋第 3 块建成，码头小铺和伙伴小屋第 5 块开放，匠人小屋约第 8 块开放。第 5 块虽然可以同时表现两座建筑落成，教学只突出一个新目标，另一项使用轻提示。

初期的收鱼船负责交易，码头小铺负责后来的持续经营收入，两者分别成立。出售鱼获不应依赖已经建成码头小铺，否则会出现没有金币建店、没有店又不能卖鱼的循环依赖。

简易小木舟可以作为第三块建设的剧情成果，不额外引入木材币或另一次付费门槛。首次钓鱼只使用附近鱼群；船只准备好后，再开放自由拖动与更多钓点。

## 七、旧功能教学如何重新安排

### 第一层：先完成挣钱与建设

前五块重点只有金币、钓鱼、交易和相邻扩张。钓鱼固定为普通鱼教学，不插入攻击、偷袭、寻珠、故事选择或需要失败重试的好鱼挑战。倍率保持 ×1。

### 第二层：家园形成后的轻养成与正向事件

| 时机建议 | 内容 | 说明 |
| --- | --- | --- |
| 第 5 块完成后 | 鱼缸与首次伙伴展示 | 可查看，可设置随行；喂养和配置仍可跳过 |
| 核心循环完成后的首次互动 | 漂流箱打捞 | 包装为寻回落海物资，衔接开场，介绍挑选需要的资源 |
| 约第 6–8 块 | 潮汐寻珠 | 使用现有十二格、5／4／3 分布和三枚匹配；一次只讲这一条规则 |
| 出海操作已理解后 | 长按自动钓鱼 | 可选提示，先让玩家知道一竿的过程和返回建设的理由 |

### 第三层：保护、挑战与中期功能

| 时机建议 | 内容 | 说明 |
| --- | --- | --- |
| 约第 8 块、家园已有价值 | 首次护盾与防守说明 | 显示当前／上限，解释保护建筑与升级扩容；演示避免让新建家园无预警受损 |
| 护盾概念理解后 | NPC 挑战漂流瓶 | 明确机器人身份，说明对方也有护盾，完成一次可视化命中 |
| 约第 10 块或已有数次事件经历 | 偷袭教学 | 先解释暂存货舱、风险与随时撤离，不影响已有钱包 |
| 相应建设条件满足后 | 装备、好鱼挑战、海上故事与设施 | 各自按真实解锁条件提示，不集中弹出 |

首次防守可使用明确标注的安全演示，或先教会玩家持有护盾再安排演示。不要在玩家还未理解损伤与修复时强制破坏第一座小屋。

原来的“捕鱼 → 扩张 → 攻击 → 寻珠 → 护盾 → 五块土地”应拆成核心经营引导与独立功能教学。两者分别保存进度，玩家不需要把所有功能课都上完，才能自由经营。

完成首次打捞／寻珠后再逐步恢复完整随机池，避免刚开放海上互动，就连续出现多个不同教程。后续随机事件仍保持既有规则与可继续状态。

## 八、页面与提示设计

始终只突出一个当前目标。例如“搭起落脚平台” → “还差 80 金币，去钓鱼” → “金币已够，返回扩张” → “家园建设 2/5”。

保留三个 Tab 的稳定位置。海岛用于建设；钓鱼在需要赚钱时亮起并介绍；鱼缸在家园形成后开放。尚未开放的入口显示简短条件，避免页面位置反复变化。

开场优先显示金币与当前任务，鱼饵在开始钓鱼时介绍，护盾在相关教学时介绍。账号、帮助与必要设置应能访问，不要求注册后才能完成第一轮。

金币不足的建设面板显示：本次价格、当前余额、差额和“去钓鱼”主按钮。金币达到目标后，任务卡提供“返回扩张”，不连续堆弹窗。

鱼宠提示继续留在鱼缸相关入口，不恢复三个主页常驻的“设置随行”任务。首次伙伴可以用临时水桶和短句建立情感联系，详细技能与喂养在玩家主动查看时再讲。

## 九、引导的自适应与容错

- 玩家已有足够金币：直接推荐扩张，不强行要求再钓一次。
- 玩家多钓了几次：正常保留收入与鱼获记录，返回后识别已达成条件。
- 玩家提前完成目标：自动推进到下一项，不要求重复购买或重复扣费。
- 玩家暂时不回家：任务保留明确目标，不反复打断钓鱼。
- 鱼饵不足：教学预算应优先避免；极端情况提供有防重复领取的教学应急补给。
- 断线、退出、切后台：保存已经完成的建设、交易和阶段；恢复到最近的安全操作节点。
- 动画未播完：不能以动画播放完成作为再次扣款或发奖的唯一条件。
- 跳过剧情：进入安全场景，不重新发放救生包。
- 完成完整引导后：允许自由操作，功能教学保留为可继续的轻提示。

第一轮只推荐一块容易理解的相邻土地；若允许自由选其他合法相邻地块，应按建设次数判断完成，避免把教程写死在某个屏幕坐标或唯一格子编号上。

## 十、旧存档与当前版本衔接

这套开场只用于新账号。已有玩家不重演落海、不扣回金币、不拆建筑、不重买土地，也不因为新引导顺序改变而再领取一遍旧奖励。

需要把“剧情看过”“核心循环完成”“各功能教学完成”分开保存。旧号根据现有进度保留已完成状态，未学过的功能可以在相关入口继续，不要求回到第一幕。

当前版本以下部分需要同步调整：

1. 新号初始 350 金币及预置待领收益，与建议的 80 金币首轮账本不一致。
2. 现有初始七块背景土地和已存在的基础建筑，需要为新号制作木板／浅礁的阶段表现。
3. 现有每步引导奖励 40 金币、4 次鱼饵、4 鱼宠粮，不能直接叠到新流程上。
4. 旧委托自动发奖、首个收藏奖励和船长补给，需统一安排展示与领取时机。
5. 现有基础建筑解锁位置需与“先立足、再经营”的顺序一致，旧号已建等级照常保留。
6. 鱼获首次交易需要独立展示，后续仍用自动结算。
7. 初始木板到小木舟，以及第一块平台到五块小岛，需要对应的模型与镜头变化。
8. 原六步强引导与随机池开放条件，需要拆分为核心经营阶段和功能学习阶段。

这里涉及实际初始状态、资源账本、场景和状态恢复的调整，完整实现不能仅靠换引导文案完成。

## 十一、可参考的短对白

落海后：“人没事……先找个能站稳的地方。”

第一次建设：“浅礁加固好了，总算有个落脚处。”

金币不足：“下一块还要 80 金币。救生包里的鱼竿，正好派上用场。”

首次交易：“这一批鱼获，港湾收购站愿意出 80 金币。留下的小伙伴，就先住在这个水桶里吧。”

返回建设：“这一竿赚来的金币，真的让小岛又长大了一点。”

家园初成：“小屋、码头，还有新朋友。这里已经有点家的样子了。”

后续打捞：“海风送来一只熟悉的箱子，像是飞机上落下的物资。”

对白用于给操作提供动机，每段应短，镜头和实际变化承担主要说明。

## 十二、验收重点

首先通过真实初次游玩确认：玩家是否知道为何扩张、为何去钓鱼、卖鱼后如何返回，以及第二轮能否自行完成。

功能验收覆盖：首次金币归零、首单足够扩张、伙伴与可交易鱼获不冲突、后续自动结算、各种余额下正确推荐、无额外金币奖励打断账本、前期不会被随机事件卡住、五块建设后强引导收尾、后置功能可跳过或继续。

恢复与兼容验收覆盖：每个关键节点刷新、弱网重试、动画中退出、重复点击、跳过剧情、提前完成、旧号登录，以及旧奖励不会重复发放。
